# AURUM CLOTHING — Final Release

Open `index.html` in a modern browser. Keep the `assets` folder next to it; it contains the brand mark, logo lockup, and local utility overshirt image.

This is a static frontend showcase. Product listings remain marked out of stock. The site does not process orders or send feedback to a server.

Portfolio founder artwork is stored in `assets/founder-dhanvith.jpg` and `assets/founder-likith.jpg`. Replace these files with approved portraits whenever you have them.
