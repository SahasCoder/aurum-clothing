# AURUM CLOTHING — Updated Release

Open `index.html` in a modern browser. Keep the `assets` folder next to it; it contains the brand mark, logo lockup, product image, and founder artwork.

The site is a static frontend. Product cards remain marked out of stock. Feedback submission currently displays a local confirmation only; connect a real submission destination before collecting customer feedback publicly.

The feedback message is optional and limited to 1,200 characters. The Feedback page includes six long-form illustrative review cards to show the intended layout. They are explicitly marked as examples and should be replaced with approved real customer reviews before being represented as genuine endorsements.
